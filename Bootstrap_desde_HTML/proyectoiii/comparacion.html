Etiquetas Obsoletas vs Modernas

Conoce cómo HTML evolucionó para ser más semántico y accesible

Con el avance de la web, muchas etiquetas antiguas se volvieron obsoletas en HTML5. Fueron reemplazadas por alternativas más modernas y semánticas para mejorar la accesibilidad y claridad del código.

Etiqueta Obsoleta Etiqueta Moderna Motivo del Cambio
<font> <span> Separar estilo del contenido (CSS externo)
<center> Estructura HTML + CSS HTML5 elimina etiquetas de presentación
<u> <span> Evitar confusión con enlaces subrayados
<strike> <del> Mejor semántica para texto eliminado
<big> <span> El tamaño se controla mediante CSS externo

Obsoleto vs Moderno

<font> vs <span>

<font> era usada para modificar color y tamaño del texto, pero mezclaba estilo con contenido.

<span> es más flexible y permite aplicar estilo de forma externa sin alterar la semántica del documento.

<center> vs Estructura HTML + Alineación

<center> ya no existe en HTML5 porque no es semántica. Hoy se estructura el contenido con etiquetas como <section> y se centra visualmente usando propiedades externas (CSS).

Más ejemplos de etiquetas obsoletas

Algunos ejemplos extra de etiquetas que quedaron obsoletas son:

  • <acronym> → Reemplazada por <abbr>
  • <tt> → Reemplazada por <code>
  • <frameset> → Eliminada, no era accesible
  • <big> → CSS controla el tamaño del texto
  • <marquee> → Eliminada, no era accesible
