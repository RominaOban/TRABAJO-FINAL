Línea de Tiempo del HTML

Conoce la evolución de HTML desde 1991 hasta HTML5

1991 – HTML 1.0

Primera versión del lenguaje.

1995 – HTML 2.0

Se estandarizan formularios.

1997 – HTML 3.2

Aparecen tablas, scripts y applets.

1999 – HTML 4.01

Separación de contenido y estilo.

2014 – HTML5

Video, audio y etiquetas semánticas.

2025 - Proyecto HTML
